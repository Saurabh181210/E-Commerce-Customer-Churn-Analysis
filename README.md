# E-Commerce-Customer-Churn-Analysis
E-Commerce Customer Churn Analysis Dashboard using Power Bi

## Project Overview

This project analyzes e-commerce customer data using Power BI to understand customer behavior, satisfaction, complaints, and churn patterns.

## Tools & Technologies

Power BI Desktop

Power Query

DAX

Microsoft Excel

## Key Performance Indicators (KPIs)

Total Customers: 3,774

Churned Customers: 631

Churn Rate: 16.72%

Average Satisfaction Score: 3.06 / 5

## Dashboard Pages

Executive Dashboard — KPIs, filters, and key insights.

Customer Analysis Dashboard — Customer demographics, payment preferences, devices, and order categories.

Churn Analysis Dashboard — Churn patterns across customer segments.

## Business Objectives

Understand customer churn patterns.

Analyze customer satisfaction and complaints.

Identify customer segments that may need retention efforts.

Support data-driven business decisions.
